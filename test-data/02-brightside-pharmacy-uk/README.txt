02 - Brightside Pharmacy Supply (United Kingdom, GBP, dates day/month)
Excel files (.xlsx); the dates are written as text like 16/10/2026 08:00, and the column names differ from the usual
(Site, Item, Qty on hand, Client, Units, Delivery date, Depot, Urgent, Destination, Expected date).

HOW TO USE (start with "Set up my business" on the start screen)
 1. Name your business and pick the country shown above.
 2. Setup tab > "Import file" on Stock counts (choose 1-...), then on Open orders (2-...), then on Incoming shipments (3-...).
    On each, check the column matching, then "Check", then confirm. Locations and products are created for you.
 3. Setup > Incoming shipments > Report a delay (or Overview > Report a delay). Pick the shipment named below and type the new arrival.
 4. Open the Overview: the orders that depended on that shipment show as at risk, with the exposed quantity.
 5. Receipts: upload with "Attach proof" in the matching editor; Gemini reads the file and you check each value before saving.
    Where to open each editor:
      - supplier-quote-pharmadirect.pdf     Suppliers > Add supplier > Attach proof (Paracetamol, deliver to Leeds Depot)
      - delay-email-medisource.png          Report a delay > Attach proof (shipment SH-3301; new arrival 22/10/2026 14:00)
      - goods-receipt-leeds-depot.pdf       Inventory > pick Paracetamol > Leeds Depot > Attach count sheet ( reads 36, file says 40)
      - purchase-order-st-marys.pdf         Orders > Edit ORD-2101 > Attach proof (Paracetamol 75, was 60)
      - transfer-booking-glasgow-to-leeds.pdf  first Setup > Add transfer route (Glasgow Depot to Leeds Depot), then Edit transfer > Attach proof
